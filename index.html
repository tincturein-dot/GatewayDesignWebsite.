(02) — Work

Doors we've drawn ourselves

Three sites, built end to end and running live. No client, no brief, no launch date — we set ourselves a problem, take it as far as it needs to go, and keep what we learn for the work that follows.

Self-initiated · Not commissioned

Aphelion — Mars Program

Scroll cinema · Product site
Live build

A single-page site for a reusable Mars vehicle, built to test one idea: that scroll position can be the only clock. It drives the video, the exploded view of the stack and every counter, so the visitor is always the one advancing time. Nothing on the page auto-plays a narrative.

Zesto — Mango Pickle

Scroll cinema · Brand & shop
Live build

A brand and shop page for a small mango-pickle house in Ratnagiri, built to answer one question: how loud can a page get before it stops being easy to buy from. All the noise is spent in one place — a full-bleed scroll film and type set at hoarding scale — and everything carrying a price sits underneath it on a flat, quiet grid.

Vaayu — Electric Motorcycle

Editorial brutalism · Brand site
Live build

A brand site for an electric motorcycle, built to find out how far 2026 CSS goes on its own. Every piece of motion is a native scroll timeline, and the wordmark compresses along a variable font's width axis as you scroll rather than being scaled or transformed. No GSAP, no ScrollTrigger, no observers, no framework. The whole site is one HTML file and two fonts, and it ships no JavaScript at all.

(03) — The studio

A small studio a wide doorway

Gateway is a design studio in Delhi. We started it around one idea we keep coming back to: a website is a threshold, and most of them are built like walls. You are asked to scroll past a brand rather than walk into it.

So we work from the entrance backwards. What does someone need in the first four seconds, what can wait, and what is only there because a template had a slot for it. Then we build the thing properly — semantic markup, real performance budgets, motion that stops when a visitor asks it to.

We take one project at a time. That is partly principle and partly arithmetic: the person you talk about the work with is the person doing it, from art direction through to the last line of production code.
